🚀 ¿Cómo desplegar esta página en tu Servidor Linux (Azure)?

Sigue estos 3 simples comandos desde tu consola para subir y publicar esta web de Pepsi:

1. Sube los cambios a tu GitHub (en Windows):
git add .
git commit -m "Creación de landing page oficial de Pepsi con Bootstrap"
git push origin main
2. En la terminal SSH de tu Servidor en Azure, clona o copia los archivos a Apache:
# Clonar tu repositorio en el directorio web de Apache:
sudo rm -rf /var/www/html/*
sudo git clone https://github.com/Zentsventh/mi-sitio.git /var/www/html/
